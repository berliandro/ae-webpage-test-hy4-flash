# Project agent instructions

## Asset handling

A reusable asset library lives at `D:\! Coding\~ shit projects\! reuseable assets` (player PNG portraits, non-uniform player hero PNGs, team icons). Lane-position SVG icons — EXP Laner, Jungler, Mid Laner, Gold Laner, Roamer — are expected later but are not available yet. Do not wait for them or block work; keep integration points flexible.

Assets are **resources, not design references**. They must never determine the pages, layout, artistic direction, required visual elements, or UX. `PRODUCT.md` (and later `DESIGN.md`) are the source of truth.

Workflow: build to the approved brief and design direction; inspect the asset library only when a concrete asset is needed; reuse what fits; source independently (sub-agents permitted) when nothing fits; verify licensing and visual compatibility. Never force an available asset into the design. Inspect dimensions and aspect ratios before use, frame consistently, and never modify files in the source folder. Existing PNGs do not override the illustrated/cartoon portrait requirement.

Full binding rules: `ASSETS.md`.
